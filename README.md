# Landing page — Swyanne Rodriguez

Projeto em React + Vite. Inclui as fotos e capas dos sete livros em `public/assets`.

## Rodar localmente

1. Instale o Node.js.
2. Abra esta pasta no VS Code ou terminal.
3. Execute `npm install` e depois `npm run dev`.

## Subir para o GitHub e publicar na Vercel

1. Crie um repositório vazio no GitHub.
2. Envie os arquivos desta pasta para o repositório (ou use `git init`, `git add .`, `git commit -m "Landing page da Swyanne"` e `git push`).
3. Na Vercel, importe o repositório do GitHub e clique em Deploy.

A configuração já usa `npm run build` e a pasta `dist`. A cada `git push`, a Vercel publica a atualização automaticamente.
